# ARCA 公開プレビュー

[空に浮かぶ街を開く](https://soratom24-spec.github.io/arca-city-preview/)

人型アバター、結晶の中央タワー、枝葉のある木、浮島、橋、滝を歩いて見られる3D体験版です。

- ゲームセンター：CPUと5カードドローポーカー
- 公園：保存済みニュースの見出しとブラウザ内コメント
- オフィス通り：Origin.のタスク・プロジェクト管理

コメント・タスクは各ブラウザ内に保存され、他の利用者とは共有されません。外部AIの実行機能は接続されていません。

公開用の静的ファイルだけを格納しています。開発資料・テスト・サーバー・DBは含めていません。
